# 文档索引

本目录保存用户、产品、设计、研发和架构决策文档. 文档状态使用 `planned`, `draft`, `accepted`, `deprecated` 或 `superseded`.

| Path                            | Type            | Status     | Purpose                          |
| ------------------------------- | --------------- | ---------- | -------------------------------- |
| `../CONTEXT.md`                 | Domain glossary | `accepted` | 统一领域语言                     |
| `standards/documentation.md`    | Standard        | `accepted` | 定义文档规范                     |
| `user/guide.md`                 | User guide      | `draft`    | 指导普通用户生成、迭代和整理图片 |
| `product/requirements.md`       | Product         | `draft`    | 记录范围、用例与验收标准         |
| `design/system-architecture.md` | Design          | `draft`    | 定义运行时组件、数据流和安全边界 |
| `design/asset-library.md`       | Design          | `draft`    | 定义文件夹 Schema 与数据模型     |
| `design/generation-workflow.md` | Design          | `draft`    | 定义生成、归档与恢复流程         |
| `design/purge-workflow.md`      | Design          | `draft`    | 定义不可逆 Purge 与恢复协议      |
| `design/web-ui.md`              | Design          | `draft`    | 定义图库信息架构与交互           |
| `development/guide.md`          | Development     | `draft`    | 定义开发、构建与运行流程         |
| `development/testing.md`        | Development     | `draft`    | 定义测试策略与验证命令           |
| `adr/`                          | ADR             | `accepted` | 记录架构决策及理由               |

状态变化、文件新增或替代关系必须同步更新本索引.
